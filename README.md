# İşTakip Mobil

İş takip programının telefon görüntüleyicisi. Bu depoda hiçbir veri yoktur; veri, programın ürettiği şifreli dosyayla telefonda yüklenir ve yalnızca o telefonda saklanır.

**Bu depoya veri dosyası (.istakip, .json) yüklemeyin.**

Üçüncü taraf bileşenler: Leaflet (BSD-2), jsPDF (MIT), MapLibre GL (BSD-3), PDF.js (Apache-2.0), DejaVu Sans yazı tipi (Bitstream Vera / DejaVu lisansı; Türkçe harfler için alt küme).
